칸에 글자를 치면 아래에 후보가 떠요 (예: 치료사 칸에 김 → 김선아, 김진수 …). 다 쓰고 엑셀로 저장을 누른 뒤, 받은 파일을 정웅쌤께 보내주세요.
날짜를 줄마다 다르게 쓰려면 아래 줄에서 바꾸면 돼요.
이동 환자·코드·치료사·시간 → 받는 치료사·받는 시간 (받는 시간을 비우면 같은 시간)
추가 치료사·시간·넣을 글자 (예: 홍길동 N-서식)
삭제 환자·코드·치료사·시간 (아래 └서식 같은 줄도 같이 지워져요)
수정 환자·코드·치료사·시간 + 바꿀 글자
