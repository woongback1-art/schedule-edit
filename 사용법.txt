스케줄 수정 프로그램 (ScheduleEdit.exe)
====================================
쌤들이 보낸 입력표(엑셀)대로 구글 시트 '스케줄 수정 최종본'의 날짜 탭을 바로 고쳐요.
파이썬 설치 필요 없어요. 칸 서식(색·테두리)은 그대로, 글자만 바뀌어요.


■ 매일 쓰는 법
 1. ScheduleEdit.exe 실행 → 위에 "✔ 연결됨: 스케줄 수정 최종본" 확인
 2. [파일 추가] 또는 [폴더 통째로]로 쌤들 입력표(엑셀)를 넣기
 3. [미리보기 → 구글 시트에 반영] 클릭
    → 아래 창에 바뀔 내용이 먼저 나와요 (초록 ✔ = 반영됨, 빨강 ✘ = 못 함 + 이유)
    → 확인하고 [예]를 누르면 구글 시트에 써요
 4. 입력표의 '결과' 칸에 ✔가 적혀서, 같은 파일을 다시 넣어도 두 번 반영되지 않아요.
    (입력표를 엑셀로 열어둔 채면 결과 칸을 못 적으니 닫고 하세요)
 ※ 잘못 반영됐으면 구글 시트 [파일 → 버전 기록]에서 되돌릴 수 있어요.

■ 쌤들 입력 화면
 [쌤들 입력 화면 만들기] → 수정요청_입력.html 저장 → 쌤들께 나눠주기
 - 크롬으로 열면 치료사·시간·환자 이름이 타자 치는 대로 후보로 떠요
 - 쌤들이 [엑셀로 저장] → 그 엑셀을 정웅쌤께 보내면 끝
 - 환자·치료사 명단은 구글 시트 '가장 최근 날짜 탭'에서 가져와요. 명단이 바뀌면 다시 만들어 나눠주세요.

■ 입력표 칸
  날짜 | 작업 | 환자 | 코드 | 치료사 | 시간 | 받는 치료사 | 받는 시간 | 넣을/바꿀 글자 | 요청한 쌤
  이동: 환자·코드·치료사·시간 → 받는 치료사·받는 시간(비우면 같은 시간)
  추가: 치료사·시간·넣을 글자
  삭제: 환자·코드·치료사·시간 (아래 └서식 같은 보조 줄도 같이 지움)
  수정: 환자·코드·치료사·시간 + 바꿀 글자
  - 날짜: 17 또는 11/17 또는 26.11.17 (탭 이름)
  - F 줄은 바로 아래 시간으로 (10:05 위 F → 10:05)
  - 시간이 틀려도 그 쌤 칸에 그 환자가 하나뿐이면 찾아서 처리하고 알려줘요


■ 처음 한 번 — 구글 연결 (15분)
 프로그램이 구글 시트를 고치려면 '서비스 계정'이라는 프로그램 전용 구글 계정이 필요해요.
 무료이고, 결제 정보 등록 필요 없어요.

 1. https://console.cloud.google.com 접속 (평소 쓰는 구글 계정으로 로그인)
    → 위쪽 프로젝트 선택 → [새 프로젝트] → 이름: schedule-edit → [만들기]
    (처음이면 약관 동의 화면이 나올 수 있어요 → 동의)

 2. 왼쪽 메뉴 [API 및 서비스] → [라이브러리]
    → 검색창에 Google Sheets API → 클릭 → [사용]

 3. [API 및 서비스] → [사용자 인증 정보] → 위쪽 [+ 사용자 인증 정보 만들기] → [서비스 계정]
    → 서비스 계정 이름: schedule-edit → [만들고 계속하기] → (역할은 선택 안 해도 됨) [완료]

 4. 방금 만든 서비스 계정(schedule-edit@...iam.gserviceaccount.com) 클릭
    → 위쪽 [키] 탭 → [키 추가] → [새 키 만들기] → JSON → [만들기]
    → .json 파일이 다운로드돼요 (이게 '키 파일')
    ※ 키 파일은 비밀번호와 같아요. 다른 사람에게 보내지 마세요.

 5. ScheduleEdit.exe → [구글 연결 설정]
    ① [키 파일 선택] → 방금 받은 .json 선택
    ② 나오는 이메일 [복사]
       → 구글 시트 '스케줄 수정 최종본' 열기 → 오른쪽 위 [공유] → 이메일 붙여넣기
       → 권한 '편집자' → (알림 보내기 체크 해제) → [공유]
    ③ 구글 시트 주소창의 주소를 통째로 복사해서 붙여넣기
    → [저장하고 연결 시험] → 위에 "✔ 연결됨" 나오면 끝!

 ※ 4번에서 '키 만들기가 정책으로 막혀 있다'는 메시지가 나오면 회사(학교)용 구글 계정이라 그래요.
    개인 gmail 계정으로 1번부터 다시 하면 돼요. (시트 공유만 그 이메일에 해주면 됨)
 ※ 키 파일과 시트 주소는 이 컴퓨터(%APPDATA%\스케줄수정)에만 저장돼요.
